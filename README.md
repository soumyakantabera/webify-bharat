# Webify Bharat

## V3 Production Build

Next.js website for Webify Bharat.

Included:
- Business-focused homepage
- Service pages
- Industry pages
- Pricing, About, Work, Blog and Contact sections
- Real business photography direction
- SEO structure
- WhatsApp conversion flow

Run:

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
npm start
```
